# Director Prompt Examples

Use only when the user requests a reusable prompt. Fill the meaningful fields
from the actual brief and omit irrelevant ones. Naming the director is an
explicit selection; these templates do not authorize provider calls or subagents.

## New game

Use $threejs-game-director to build [game idea] for [target devices]. The player
should [core verb and objective], with [pressure/progression] and [visual intent].
Scope: [included systems and exclusions]. Follow the project’s architecture and
production rules, select only needed phases, and verify the playable result
through real input. Report the result, how to run it, relevant evidence and gaps.

## Existing game across named systems

Use $threejs-game-director to improve [named gameplay, visual and/or UI systems]
toward [observable outcome]. Current issues: [observed evidence]. Preserve
[existing design contracts]. Coordinate the dependencies, implement the complete
scoped result and verify it with the project task matrix. Keep human visual
approval and release status separate from agent inspection.

## Release preparation

Use $threejs-game-director to coordinate [named release/milestone] against the
existing acceptance criteria. Resolve its in-scope defects, verify the required
production and player paths, and report passing, failed or unverified gates with
their evidence. Deployment is included only if expressly requested.

A single graphics pass uses $threejs-aaa-graphics-builder or the owning specialist;
a single gameplay or UI change uses its specialist directly. “Premium” alone
does not require director orchestration, a scorecard or every game layer.
