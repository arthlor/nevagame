# Whole-Game Visual Review Checklist

Use for an explicitly requested whole-game review, selecting criteria that fit
the game. This is critique guidance, not a replacement for project gates. A
scoped graphics task does not inherit whole-game completion requirements.

- The intended loop works through real player input with clear state feedback.
- Forms, materials, spacing and lighting express the accepted art direction.
- Required subjects, routes and interactions remain readable during play.
- UI supports the game, real content and supported input/viewport modes.
- Effects and audio, where part of the brief, communicate rather than obscure.
- Repeated assets preserve identity while avoiding distracting repetition.
- The implemented result respects project resource and compatibility contracts.
- Evidence supports the actual claims; remaining defects and approval gaps are explicit.

Do not require a fixed number of enemies, rewards, layers or generated assets.
Neva remains no-combat, uses its catalog/Blender owners, and records visual
acceptance under `04` §19 without numeric style scores.
